## UI work

Before creating, editing, or moving **any** UI-related code (a screen, composable, card, button,
navigation, dimension, typography, padding, image, or responsive behavior), **read
[`UI_ARCHITECTURE.md`](UI_ARCHITECTURE.md) first and follow its rules.** That file is the single
source of truth for UI architecture in this project. Do not duplicate its content here.
