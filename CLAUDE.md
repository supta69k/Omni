# CLAUDE.md — Omni

## UI work

Before creating, editing, or moving **any** UI-related code (a screen, composable, card, button,
navigation, dimension, typography, padding, image, or responsive behavior), **read
[`UI_ARCHITECTURE.md`](UI_ARCHITECTURE.md) first and follow its rules.** That file is the single
source of truth for UI architecture in this project. Do not duplicate its content here.

## Codesight context (start here, explore less)

Precompiled codebase context lives in `.codesight/` (generated by `npx codesight`; not part of
the app build — never add it to Gradle).

Before coding:

1. Read `.codesight/wiki/index.md` first, then only the relevant article. For how the app is
   wired (navigation, DI, repositories, Firestore collections, models) read
   `.codesight/wiki/architecture.md`; for the composable inventory read
   `.codesight/wiki/ui.md`.
2. Locate existing implementations before creating new ones; reuse existing Compose components,
   theme (`ui/theme/`), navigation (`MainActivity`'s `AppScreen` router), ViewModels, and
   repositories (`data/repo/` — interface + Firestore impl + Preview fake).
3. Wiki articles are navigation aids, not source of truth — read the actual files before
   changing anything, and don't explore project-wide when one article answers the question.
4. `npx codesight --wiki` regenerates `index.md` and drops hand-added lines — re-add the
   `architecture.md` link after a regen. Regenerate after significant code changes.

Figma work (Omni's UI is a 1:1 build of the Figma design on a 415dp artboard):

1. Inspect only the requested Figma frame.
2. Use the codesight/wiki context above to find existing composables first; reuse them and the
   existing colors, typography, and dimensions. Do not create duplicate components.
3. Do not modify unrelated screens, and do not refactor Omni merely to match Figma; do not
   change the architecture unless explicitly requested.

Secrets: `.codesight/` content is AI context that may be committed — it must never contain
secret values (`google-services.json`, `tools/service-account.json`, `local.properties`, API
keys). It currently contains none; keep it that way when editing it by hand.
